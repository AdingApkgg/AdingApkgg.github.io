原神 mod モジュール導入チュートリアル

作成日2023-02-21|更新日2023-04-23|ゲーム私設サーバーとMOD
|総文字数:514|読む時間:2分|閲覧数:|コメント数:

はじめに

原神私服mod の導入は Windows システムのみ対応しています。それ以外のシステムの方はこのチュートリアルを終了してください！

多少のコンピューターの基礎知識が必要です（本当に • 少しだけでも可）。ない方はこのチュートリアルを終了してください、ありがとうございます！

操作中に何か問題が発生した場合はコメントでご連絡ください。チュートリアルを見たくない？ （それならなぜ mod をやるのか、このチュートリアルを終了してください）

公式サーバーでは mod を使用しないでください。アカウント停止になります！！

同じキャラクターや武器などのアイテムに複数の mod を適用しないでください。軽ければバグ（モデルの痙攣）、重ければゲームのクラッシュ、ブルースクリーンによるフリーズ、PC の破損につながります！！

すべてのウイルス対策ソフトを削除するか、無効にしてください（無効にできる場合に限ります）

タダ乗り派の皆さん、成功したら右下のコメントボタンをクリックして一言残してくださいね(～￣ ▽ ￣)～

mod ツールの使い方

123 クラウドディスク（解凍パスワード：saop.cc）：https://www.123pan.com/s/VMelVv-MI1zH.html

天翼クラウドディスク（アクセスコード：0gx0）：https://cloud.189.cn/web/share?code=3yuUbiQFFV73

クラウドディスクからYS MOD.zip圧縮ファイルをダウンロードし、任意のフォルダまたはドライブに解凍してから、YS MOD>3dmigoto フォルダに移動します。

记事本 でd3dx.iniファイルを編集し、Win + F で検索ボックスを開き、YuanShen.exe を検索して「検索」をクリックします。

Z:\ys\yscn\Genshin Impact\Genshin Impact Game\YuanShen.exe を、あなたの原神プライベートサーバーのゲーム本体YuanShen.exeの実行ファイルパスに置き換え、Ctrl + S で保存して終了します。

パスの記入方法はあらかじめ用意されているパスZ:\ys\yscn\Genshin Impact\Genshin Impact Game\YuanShen.exeを参考にしてください。記入できないなんて言わないでください（このチュートリアルを終了してください）

次に、フォルダ内の3DMigoto Loader.exe実行ファイルを右クリックして管理者として実行し、mod ツールを起動します。続いて原神プライベートサーバーのゲームに入り、入る際に滴~という音が鳴るかよく聞いてください。鳴れば mod ツールが正常に動作しています。もしクラッシュする場合は、何度か入り直せば大丈夫です。ゲームに入ってキャラクターを操作できるようになったら、女性キャラを何人か切り替えれば効果が確認できます 😏～

ins またはテンキーの 0 は mod ソフトの情報表示のオン／オフ切り替えで、u で原神の UI を非表示にできます。

どれも効かない場合は、どのキーで操作できるかご自分で調べてみてください。

mod を入れすぎると、ゲームに入ったときに大量の情報が表示されますが、しばらく待てば消えます。

mod ファイルのインストール

123 クラウドディスク mod ファイルミラー 1：https://www.123pan.com/s/VMelVv-kVmzH

123 クラウドディスク mod ファイルミラー 2：https://www.123pan.com/s/VMelVv-oVmzH

Mod サイト：https://gamebanana.com/mods/games/8552

神秘のリンク 😏：https://github.com/SilentNightSound/GI-Model-Importer

mod ファイルのクラウドディスクからお気に入りの mod ファイルをダウンロードし、次のステップへ進みます。

または mod サイトでさらに多くのものを選ぶこともできます。このサイトは「魔法のインターネット」が必要です。「魔法のインターネット」が何かわからない場合は、このリンクを使用しないでください。

mod の圧縮ファイルをダウンロードしたら、ファイルを3dmigoto\Mods\modフォルダ内に解凍します。

必ずフォルダごとの形式になっている必要があります。ファイルが散らばっている場合は、ご自身で新建文件夹してください（フォルダ名は英語である必要があります）。

散らばったファイルをその中に入れてから、上記の手順に従ってゲームに入れば完了です。
