  1. 内蔵 icon
パラメータ使い方
class【任意】識別子。識別子ごとに異なる配色になります （ default / primary / success / info / warning / danger ）
no-icon【任意】icon を表示しない
style【任意】設定内の style を上書きできます （simple/modern/flat/disabled）
  1. 外部 icon
パラメータ使い方
class【オプション】識別子。識別子ごとに異なる配色になります（ default / blue / pink / red / purple / orange / green ）
no-icon【オプション】カスタム icon を設定できます（fontawesome アイコンのみ対応、no-icon の設定も可能）
style【オプション】設定内の style を上書きできます（simple/modern/flat/disabled）

2020-07-24 2.6.6 -> 3.0

  1. hexo-lazyload-image プラグインがある場合は、削除して最新バージョンを再インストールし、lazyload.isSPA: true を設定する必要があります。
  2. 2.x バージョンの css と js は 3.x バージョンには適用されないため、use_cdn: true を使用している場合は削除する必要があります。
  3. 2.x バージョンの fancybox タグは 3.x バージョンで gallery に名前が変更されました。
  4. 2.x バージョンのトップ固定 top: true は pin: true に変更され、layout: page のページにも同様に適用されます。
  5. hexo-offline プラグインを使用している場合は、アンインストールを推奨します。3.0 バージョンでは pjax サービスがデフォルトで有効になっています。

2020-05-15 2.6.3 -> 2.6.6

追加の処理は不要です。

2020-04-20 2.6.2 -> 2.6.3

  1. seotitle を全体検索し、seo_title に置き換えます。
  2. group コンポーネントのインデックス規則が変わりました。group コンポーネントを使用する記事内では、group: group_name に対応するコンポーネント名は group_name でなければなりません。
  3. group コンポーネントのリスト名は、記事の short_title が優先的に表示され、次に title が表示されます。

段組み tab

{% tabs Unique name, [index] %}

<!-- tab [Tab caption] [@icon] -->

Any content (support inline tags too).

<!-- endtab -->

{% endtabs %}

  1. 一意の名前：

    • タブブロックの一意の名前です。カンマは含めません。

    • 各タブとそのインデックス番号のプレフィックスとして #id で使用されます。

    • 名前にスペースが含まれる場合、#id の生成時にはすべてのスペースがダッシュに置き換えられます。

    • 現在の投稿／ページの URL 内でのみ一意である必要があります！

  2. [index]：

    • アクティブなタブのインデックス番号です。

    • 指定しない場合は最初のタブ（1）が選択されます。

    • index が -1 の場合、どのタブも選択されません。

    • 省略可能なパラメータです。

  3. [Tab caption]：

    • 現在のタブのタイトルです。

    • タイトルを指定しない場合、タブインデックスのサフィックスが付いた一意の名前がタブのタイトルとして使用されます。

    • タイトルを指定せず、アイコンのみを指定した場合はタイトルが空になります。

    • 省略可能なパラメータです。

  4. [@icon]：

    • FontAwesome のアイコン名（完全な名前で、「fas fa-font」のような形式）。

    • スペースあり・なしのどちらでも指定できます。

    • 例えば「Tab caption @icon」と「Tab caption@icon」。

    • 省略可能なパラメータです。
