PC Windows Tutorial

Preparations Before You Start

Your PC needs to be running Win10 or later. Win7 isn’t strictly incompatible, but there’s a very high chance it won’t work, so upgrading to Win10 is recommended.

Turn off or delete all antivirus software!!

First, you need to have the official (CN) or international client already installed — it cannot be the B server version!

If you don’t have the official (CN) or international client, go download and install it from the Genshin Impact official website first…

Genshin Impact CN official site: https://ys.mihoyo.com/main

Genshin Impact international official site: https://genshin.hoyoverse.com/en/home

Private Server Play Guide

Tianli

In the Tianli private server command server, you can freely use commands to obtain anything you want. For example, using /give all lv90 r5 c6 x999 gives you all characters and weapons at max level, max constellation, and max refinement, plus every item; or using /give 223 x9999 gives you 9999 Intertwined Fates, and so on. All Tianli servers are provided free of charge. If you paid for one, please request a refund and report the reseller.

Tutorial
  1. Download the Tianli Launcher V1.7.1 and open it as administrator
PC线路一 PC线路二
  1. Click Settings and select the game path for Genshin Impact 3.7. You can try auto-search first; if auto-search doesn’t work or throws an error, specify the path manually.

寻找原神游戏路径

Right-click the “Genshin Impact” shortcut on your desktop and click “Open file location”.
（If you didn’t create a desktop shortcut when installing Genshin Impact, you can use the “Search” function to search for “Genshin Impact” and then click “Open file location”. Or search your computer for “Yuanshen”.）
If you still can’t find it, you can 点此跳转, or search on Baidu

  1. Back on the launcher’s home page, select “3.7 Command Server” and click “Start Game”

(If you want to play the B server or a server for another version, be sure to select the corresponding game version when choosing the game)

  1. Wait for the game to load. On the login screen, just enter any username and password (use a username made of English letters and numbers). After entering them, logging in will automatically create an account, and you can use the account from your first login afterward.

Private servers have no password system — the username alone is the only credential for your account, so try to use a longer, unique username

  1. After logging in, it may download some files; please be patient and wait for the download to finish. Once it’s done, open the door and you can enter the game and play!

On the subsequent server selection screen, please check the website https://zhuangtai.casks.me and choose the sub-server with the fewest players to play on, reducing latency and improving your experience.
You can also choose the normal command server or the story-fix server, though the story-fix server may not be very stable. If you want to experience the full story, you can play the B server at https://casks.me/1157/

Click the three-dot button in the bottom-left corner, choose to add a bot named 输指令给我, and send your commands to it.
Use the /help command to see the available commands. You can use a command generator as an aid (though some of its commands are a bit outdated and won’t work)

Command generator: https://cmd.d2n.moe/new

The Patch-and-Proxy Method (General)

First, press Win + E to open 此电脑

Pick a partition with more than 80G of free space, enter it, create a new folder, and name it yuanshen-sf

Run the official Genshin Impact launcher, click the three lines to the right of “Start Game” > Installation Location > Use another folder,

Click the blank area to the right of the path above 此电脑, press Ctrl + C to copy the game path shown there. In my case the game path is D:\Genshin Impact\Genshin Impact\Genshin Impact Game

Don’t just copy my game path — everyone’s path can be different!

In the box above 此电脑, press Ctrl + V to paste the path you just copied, then press Enter

You will now be at the root directory of the official Genshin Impact game. Click the up arrow in the top-left corner to go to the parent directory

Right-click the Genshin Impact Game folder (the Genshin Impact game itself) and copy it into the yuanshen-sf folder you created earlier

While the copy is in progress, go ahead and download what you’ll need later

  • GcTools-v1.9.0.exe: a very handy PC command generator — foolproof and quick to pick up

Mobile Android Tutorial

Preparations Before You Start

Your phone must be running Android 10 or above!!

Why is there no Apple iOS version? Because we’ve given up on it — switch to Android…

Make sure you have more than 22GB of free storage, enough to download another copy of Genshin Impact

Go to the HoYoverse pass registration site and register a HoYoverse pass account.

If you’ve already registered a Genshin Impact international server account before, you can skip this step!

Genshin Impact international registration: https://account.hoyoverse.com/#/register/email?cb_route=%2Faccount%2FaccountInfo

If you have an email address, just register by following the prompts.

If you don’t have one, use the email that comes with QQ.

The format is: 你的QQ号@qq.com — this is the email that comes with your QQ

The verification code will be delivered inside QQ. Fill in the rest as prompted, then click register.
